Installation, son et confidentialité

Sur Android : ouvre le lien sécurisé dans Chrome, puis choisis « Installer l’application » ou « Ajouter à l’écran d’accueil » dans le menu. Sur iPhone ou iPad : ouvre le lien dans Safari, puis Partager → Sur l’écran d’accueil.

Attends le message « Jeu prêt hors connexion » avant de couper Internet. Pour la voix hors connexion, une voix française locale doit être disponible dans les réglages vocaux du téléphone. Sinon, le jeu propose un mode sans son. Les prononciations varient selon la voix de l’appareil ; les corrections existantes sont conservées.

Aucun compte, publicité ou suivi ajouté. Les niveaux réussis sont enregistrés uniquement dans ce navigateur ; ils ne sont pas synchronisés entre appareils. Effacer les données du site efface cette progression.

Pour une installation sur téléphone, cette copie doit être publiée sur un hébergement HTTPS. L’aperçu sur ordinateur ne constitue pas un lien public et ne publie rien sur les boutiques.
